BLOG IMAGE UPLOAD FEATURE - IMPLEMENTATION COMPLETE
====================================================

WHAT WAS ADDED:
--------------

1. BACKEND COMPONENTS:

   a) Image Upload Service (backend/services/imageUpload.service.js)
      - Automatic image processing with Sharp
      - Creates multiple sizes: thumbnail (300x200), medium (800x600), large (1200x900)
      - Converts to WebP format for optimization
      - Stores in: backend/uploads/blog-images/
      - Manages image deletion

   b) Blog Image Controller (backend/controllers/blogImage.controller.js)
      - uploadFeaturedImage: Upload new blog image
      - updateBlogImage: Update existing blog image
      - removeBlogImage: Delete blog image
      - Automatic cleanup of old images

   c) Image Upload Routes (added to backend/routes/blog.routes.js)
      - POST /api/blog/admin/image/upload - Upload image
      - PUT /api/blog/admin/:id/image - Update blog image
      - DELETE /api/blog/admin/:id/image - Remove blog image

2. FRONTEND COMPONENTS:

   a) ImageUpload Component (frontend/src/components/ImageUpload.jsx)
      - Drag & drop support
      - Live preview
      - File validation (type & size)
      - Loading states
      - Image metadata display
      - Alt text, caption, credits fields
      - Aspect ratio support
      - Uses environment variables for API URLs

   b) Updated AdminBlogEditor (frontend/src/pages/blog/AdminBlogEditor.jsx)
      - Integrated ImageUpload component
      - Featured Image panel in sidebar
      - Image metadata management
      - Auto-saves image data with blog

3. DIRECTORY INITIALIZATION:
   - Script: backend/initDirectories.js
   - Creates uploads/blog-images folder automatically

HOW TO USE:
-----------

1. Go to Admin Panel > Blog > Edit/Create Blog
2. Scroll to "Featured Image" section in sidebar
3. Click to upload or drag & drop an image
4. Add alt text for accessibility
5. Optionally add caption and credits
6. Save the blog post

The image will be automatically optimized and multiple sizes will be created for different use cases.
